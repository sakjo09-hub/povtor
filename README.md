# Повтор

Локальное веб-приложение для самостоятельного повторения русских слов на iPhone.

Приложение поддерживает:

- пропущенные буквы;
- слитное, раздельное и дефисное написание;
- постановку ударения;
- собственные наборы слов;
- повтор ошибок и локальную статистику;
- автономную работу после установки на экран «Домой».

Рабочая версия: https://sakjo09-hub.github.io/povtor/

Пользовательские наборы и результаты сохраняются только в браузере устройства и не отправляются в репозиторий.
