# Повтор

Локальное PWA-приложение для личных тренировок по русскому языку.

## Что работает

- собственные наборы слов;
- добавление слова одним вводом и выбор скрываемых букв нажатием;
- задания с пропущенными буквами и быстрым выбором ответа;
- задания на одну или две одинаковые буквы;
- слитное, раздельное и дефисное написание;
- постановка ударения нажатием на гласную;
- случайный порядок заданий;
- сохранение ошибочных слов во вкладке «Повтор» до отдельного правильного повторения;
- итоговая мини-статистика и список ошибок после каждой тренировки;
- понятный прогресс: закреплённые, новые и требующие повтора слова;
- выбор 20 случайных слов из большого набора;
- хранение данных в браузере;
- экспорт и импорт резервной копии;
- офлайн-режим после первой загрузки через HTTPS.

## Локальный запуск

На Windows дважды нажмите `start-povtor.cmd`. Пока окно запущено, приложение доступно в локальной сети по адресу, указанному в нём.

Или откройте папку через любой статический HTTP-сервер:

```powershell
python -m http.server 4173 --directory .
```

Затем откройте `http://localhost:4173`.
